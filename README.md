## Aperçu

Ce projet crée un site de classement de films avec l'API "TMDB" en prenant en compte l'apparence et les fonctionnalités dynamiques au sein du projet.

## Technologies utilisées

- **HTML5** : Pour la structure du site
- **CSS3** : Pour le design et le style
- **JavaScript** : Pour l'interactivité et la gestion des comportements dynamiques
- **API TMDB** : Pour récupérer les films avec leurs informations (titre, description, etc)
- **Google Font** : Pour la font du site
